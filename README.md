# Bilibili 高等级用户公开信息采集助手

一个适合学习与作品集展示的 Python 小工具：输入 Bilibili 视频链接或 BV 号，从公开评论账号中低频抽样 Lv5 / Lv6 用户，并整理公开账号等级、大会员状态、学校与最早可见动态信息。

## 功能

- 粘贴视频链接或 BV 号后直接运行
- 默认抽取 50 个不重复的 Lv5 / Lv6 账号
- 记录账号等级与大会员状态
- 在登录状态可用时读取用户公开填写的学校
- 回溯最早可见公开动态，并识别“转正会员”系统动态
- 分别导出完整结果与扫描日志 CSV
- 遇到验证码、HTTP 412 或 429 时停止，不提供绕过机制

## 快速开始

### macOS

双击 `开始运行.command`，粘贴视频链接或 BV 号并按回车。首次运行会自动创建 `.venv` 并安装依赖。

如果从 GitHub 克隆后 macOS 提示文件不可执行，请先在项目目录运行 `chmod +x 开始运行.command`，再双击启动。

### 终端

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

结果保存在 `output/`。

## 可选登录状态

未登录时程序会自动使用基础抽样模式。若要尝试读取更多公开主页与动态字段，可在运行前临时设置：

```bash
export BILI_COOKIE='你的 Cookie'
```

Cookie 仅从环境变量读取，程序不会保存 Cookie，也不会自动读取浏览器登录信息。请勿将 Cookie 写入源码、截图或提交到仓库。

## 数据口径

Bilibili 没有公开、可靠的官方注册时间字段。本工具只提供代理指标：

1. “转正会员”系统动态时间：较强的加入时间代理。
2. 其他最早可见公开动态时间：较弱的公开活动时间代理。

若动态未完整回溯，程序会标记为“未判定”，不会将最早可见动态伪装成注册时间。

## 配置

在 `bili_helper/config.py` 中可修改样本数、最低等级、翻页上限、请求间隔与评论排序方式。

## 使用边界

- 仅用于低频、少量的公开数据研究与 Python 学习。
- 请遵守平台规则、robots 约定及适用法律法规。
- 不采集评论正文、IP 属地或主页地址。
- 不提供代理池、账号轮换、验证码识别、并发轰炸或其他绕过风控的能力。
- 发布分析结果时应匿名化 UID 与昵称，仅展示必要的聚合结论。
- 平台接口可能变化，本项目不保证长期可用，也不隶属于 Bilibili。
