# Bilibili 高等级用户公开信息采集助手

一个适合学习与作品集展示的 Python 小工具：输入 Bilibili 视频链接或 BV 号，从公开评论账号中低频抽样 Lv5 / Lv6 用户，并整理公开账号等级、大会员状态、学校与最早可见动态信息。

## 功能

- 默认抽取 50 个不重复的 Lv5 / Lv6 账号
- 记录账号等级与大会员状态
- 登录状态可用时读取用户公开填写的学校与最早可见动态
- 识别“转正会员”系统动态
- 导出完整结果与扫描日志 CSV
- 遇到验证码、HTTP 412 或 429 时停止，不提供绕过机制

## 快速开始

macOS 用户双击 开始运行.command，粘贴视频链接或 BV 号并按回车。首次运行会自动创建虚拟环境并安装依赖，结果保存在 output/。

## 数据口径

Bilibili 没有公开可靠的官方注册时间字段。本工具只提供代理指标：“转正会员”系统动态时间或其他最早可见公开动态时间。若动态未完整回溯，程序会标记为“未判定”，不会伪造加入时间。

## 使用边界

- 仅用于低频、少量的公开数据研究与 Python 学习
- 请遵守平台规则及适用法律法规
- 不采集评论正文、IP 属地或主页地址
- 不提供代理池、账号轮换、验证码识别或并发轰炸
- 发布分析结果时应匿名化 UID 与昵称
- 本项目不隶属于 Bilibili
